<a id="how"></a>

## How this list works

- Entries come from [TGbox](https://tgbox.cc/en): submitted by owners and users through the [bot](https://t.me/tgboxccbot), reviewed by admins, then re-checked by a crawler every few hours.
- A GitHub Action rebuilds this README every day from [`/data/entries.json`](https://tgbox.cc/data/entries.json) — a copy is kept in [`data/entries.json`](data/entries.json).
- Only public entries are listed. Adult, gambling, scam and other illegal content is not accepted.

## Add or report an entry

- **Fastest:** send the link to [@tgboxccbot](https://t.me/tgboxccbot?start=submit) — it is reviewed and appears here the next day.
- Or [open an issue](https://github.com/TGrpg/awesome-telegram/issues/new/choose). Please don't edit the README by hand: it is generated and your change would be overwritten.
- Found a dead, wrong or harmful entry? [Report it](https://github.com/TGrpg/awesome-telegram/issues/new?template=report.yml).
